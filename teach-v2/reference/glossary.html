术语表

课程使用的稳定词汇。定义强调“它拥有什么权力”以及“它不能替代什么”，便于源码评审与验收沟通。

架构与能力

ProjectProfile

项目治理档位：Lite、Standard 或 Governed。它是 Capability Compiler 的输入，不是一条独立硬编码流水线。

CapabilityPlan

将 Profile、Risk、Policy、Provider 与依赖闭包编译成的权威能力决议，包含活动模块、绑定和 Operation DAG。

Operation DAG

一次工作流实际执行的有向无环图。未启用模块不产生节点、绑定、Checkpoint 或空结果。

Kernel

所有 Profile 共享的确定性主干，例如 Capture、Plan、Context、Execute、Verify 与 Snapshot。

Module

由 CapabilityPlan 条件物化的治理能力，例如 Impact、Design、Evaluation、Strict TDD 与 Audit。

Port

模块公开的类型化能力边界。Port 存在只证明“允许连接”，不证明生产代码已连接 Provider 或消费者。

Relation Type 的业务语言

下面统一按 source → target 阅读。关系名不是近义词标签；每一种都保留独立的端点类型、审计问题和传播语义。

关系 业务语言 主要审计问题
DERIVES_FROM 当前工件由目标工件推导或演化而来。 它的来源依据是什么？
SUPERSEDES 当前修订正式取代目标的旧精确版本。 哪个旧版本已不再有效？
GENERATED_BY 当前记录或工件由目标 Run、编译器或过程生成。 是谁、在哪次运行中产生它？
RESUMES 当前 Operation 接续目标中断运行的合法前缀。 恢复自哪次运行、可复用到哪里？
DECOMPOSES_TO 上层目标或需求拆解为目标中的下层可执行项。 上层义务被拆成了什么？
ADDRESSES 当前工件或工作回应目标需求、问题或 Finding。 它声称解决哪个问题？
CONSTRAINED_BY 当前对象的合法形状或行为受目标约束。 哪些边界限制了它？
GOVERNED_BY 当前对象的生命周期由目标 Policy 或治理规则控制。 谁拥有治理权？
SHAPES 当前事实影响目标方案的形状，但不表示完整兑现。 什么输入改变了设计取舍？
REALIZES 当前代码工件落地目标设计组件。 设计结构由哪个实现载体承载？
IMPLEMENTS 当前任务落实目标需求、决策或设计义务。 哪项工作负责兑现承诺？
VERIFIES 当前 Test 或 Evidence 检验目标 Assertion/对象。 什么证据检查了这个声称？
EVALUATES 当前 Evaluation 按规则裁判目标工件或运行。 谁按什么准则给出质量判断？
EXECUTES 当前 Run 实际执行目标 Task、Plan 或命令。 哪个运行承担了执行？
INVOKES 当前调用者触发目标 Port、Provider 或 Tool。 生产调用从哪里真正发生？
PRODUCES 当前动作或运行产出目标工件、记录或 Evidence。 这个结果由哪次动作产生？
SUPPORTS 当前 Evidence 增强目标声称的可信度。 哪些证据支持结论？
REFUTES 当前 Evidence 直接否定目标声称。 什么证据证明结论不成立？
VIOLATES 当前对象违反目标 Policy、合同或不变量。 具体破坏了哪条规则？
CONTAINS 当前容器在该版本中包含目标子对象。 对象属于哪个集合或边界？
SPECIFIES 当前合同或设计精确定义目标对象的要求。 目标应满足的精确规范在哪里？
DEPENDS_ON 当前对象要成立或执行，必须先有目标对象。 缺少什么前置条件就不能继续？
USES_CONTEXT 当前 Task/Run 在目标 ContextBundle 的精确版本上执行。 执行时绑定了哪份上下文？
CAPTURES 当前记录收录目标输入事实或外部观察。 哪份记录固定了这项输入？
BLOCKS 当前 blocker 阻止目标对象继续推进。 什么条件正在阻塞谁？
REQUESTS_APPROVAL_FOR 当前 ApprovalRequest 请求放行目标对象的精确版本。 正在申请批准什么？
RESOLVES 当前批准决定处理并结束目标 ApprovalRequest。 哪个请求已被闭合，结果是什么？
APPROVES 当前 Approval 明确放行目标对象的精确版本。 哪个对象 digest 获得授权？
DIAGNOSED_BY 当前 Finding 或失败由目标 RCA/诊断解释。 根因分析在哪里？
PROPOSES_CHANGE_TO 当前 ImprovementCandidate 提议修改目标对象。 建议改什么，而非已经改了什么？
TRIGGERS 当前事件按规则触发目标动作、流程或重新分析。 哪个确定事件启动了下一步？
MAY_IMPACT 当前 ChangeSeed 可能波及目标组件、文件或要求。 候选影响范围包含谁？

两组易混关系：REALIZES 回答设计组件由哪个代码工件承载， IMPLEMENTS 回答哪项任务兑现义务；RESOLVES 回答请求生命周期是否结束， APPROVES 回答哪个对象版本获得授权。上层可以分组，底层不可合并。

事实、图与存储

Node

Graph 中的类型化工程对象，例如 Requirement、Task、Evidence 或 Snapshot。

Edge

两个 Node 之间的类型化关系。合法端点不代表 Impact Engine 会自动传播。

Artifact Graph

长期工程知识视图，关注意图、需求、设计、组件、代码和测试怎样关联。

Execution Graph

运行治理视图，关注 Plan、Task、Context、Run、Gate、Evidence 与恢复记录。

Ledger

Git-native、append-only 的权威记录。Lifecycle Event、Node、Edge、Approval 与 Evidence 由它决定完成真相。

Projection

从 Ledger 可重建的读侧表示，例如 SQLite、Markdown 或 Dashboard View；投影不能反向升级为事实。

Live Spool

保存心跳、相位和输出摘要等 Observation Event 的可删除实时层，不参与完成裁决。

Digest

canonical 内容的稳定摘要。Approval、Context、Evidence 或 Binding 的输入漂移会改变 digest 并触发失效。

需求、执行与完成

Criterion

一条原子验收准则。每个 accepted Criterion 恰好编译出一个 canonical Assertion。

Test seed

由 Criterion 稳定派生的测试图节点，为后续 Assertion 与 Evidence 提供追踪锚点。

Assertion

Harness 确定性编译的可判定验收义务；模型可以分组，不能创造、合并或删除它。

TaskTddContract

Task 的不可变 TDD 合同，绑定 Assertion、Test、Design strategy、Plan 与 CapabilityPlan digest。

Evidence

带来源、类型、绑定和 freshness 的结果记录。Agent 自述、日志片段或旧 commit 测试不能自动成为当前 Evidence。

TaskVerdict

逐 Assertion 消费有效 Evidence 后的任务裁决。Provider Run 成功不等于 TaskVerdict 通过。

Snapshot

Iteration 完成后的权威锚点，记录 source commit、ledger commit、Gate、Evaluation、Verdict 与遗留风险。

Fail closed

输入、绑定或证据不完整时停止并返回 typed blocker，而不是猜测、降级或制造空壳成功。

模型治理与状态

Model Slot

Capability Binding 使用的五个固定槽位：Impact、Design Review、Plan、Feedback、Grounded Synthesis。

Purpose

Grounded Synthesis 的固定用途：Discovery、Context Enrichment、Approval Brief、Iteration Narrative。

Provider Binding

将 slot/purpose 与 Provider、Prompt、Schema、预算和失败模式绑定的可摘要记录；凭据材料不进入 digest。

Managed Runner

统一模型调用状态机，只接受编译 Prompt 与 Binding，记录 planned 到 consumed/failed 的全过程。

已连通

当前生产消费点存在，并有当前提交上的自动化或 Ledger 证据；仍需注明是仓库内还是外部环境。

部分连通

至少一部分链路有实现或历史真实证据，但当前提交的外部 Provider、完整闭环或发布环境证据尚不完整；必须注明具体维度，不能理解为“代码接了一半”。

未连通

只有目标设计、类型或孤立组件，当前生产调用链没有消费者。

Evidence scope

证据适用的 commit、平台、Provider、Profile、命令和时间范围。脱离 scope 的“通过”不能外推。
