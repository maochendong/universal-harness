安全结论

可以声明仓库内模型链路已生产接线；真实外部 Provider 对当前提交仍为部分连通，必须单独补证。

解除“部分连通”的最小动作

1
固定当前 source commit

不要在调用过程中继续变更代码；所有记录绑定同一个提交。

2
由受信 host 注入凭据

凭据只存在环境中；提交的证据不得包含 key、Prompt 原文或原始响应。

3
复跑真实 Provider driver

覆盖至少一个 required Profile，并保留 invocation id、slot/purpose、digest 与 typed result。

4
更新范围化证据

逐 slot 写明 consumed、validated、failed 或 blocked；不能把正确 fail closed 伪装成领域完成。
