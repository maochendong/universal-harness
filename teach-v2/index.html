Kernel 是什么

每次迭代都必须经过的固定控制脊柱：Capture、能力决策、Plan、Context、Execute、Verify、Snapshot。它保证所有 Profile 共享同一套生命周期语义。

Module 是什么

按 CapabilityPlan 激活的可选子图，例如 Impact、Design、Evaluate、Audit。未激活时不应产生节点、Binding 或 checkpoint。

模型能做什么

模型或 Provider 只能提出结构化候选；确定性 Schema、Compiler、Validator 与 Evidence 决定候选能否进入事实层。

什么才是系统真相

Git-native Ledger 与已提交 Snapshot 是权威；SQLite、Markdown、Dashboard 和 Live Spool 都是投影或观察面。
