Kernel

所有 Profile 共用的确定性控制脊柱；固定生命周期语义，不等于操作系统内核。

Module

由 CapabilityPlan 条件物化的能力子图；inactive 时不应留下节点、Binding 或 checkpoint。

候选与裁决

模型、Adapter 和 Agent 可以提出候选；Schema、Policy、Validator、Evidence 与 Ledger 决定能否接受。

权威与投影

Git-native Ledger 和 committed Snapshot 是事实；SQLite、Dashboard、Markdown 与 Live Spool 是可重建读取面。
